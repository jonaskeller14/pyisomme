# FMVSS 208 report scope and assumptions

## Source

The report is based on **49 CFR 571.208, Standard No. 208; Occupant crash
protection**, up to date as of 2022-10-14, from
`references/FMVSS/B04.w8z738446fxw0xa22it81751sl8noj63801729751.pdf`.

## Implemented scope

`FMVSS_208` assesses one modern adult frontal rigid-barrier test containing a
driver and a front outboard passenger. The implemented measurement requirements
are the post-2010 adult criteria referenced by S14.4:

- 50th-percentile adult male: S14.5 with S6.1, S6.2(b), S6.3, S6.4(b),
  S6.5, and S6.6.
- 5th-percentile adult female: S15.1/S15.2 with S15.3.
- Per occupant: containment, HIC15, chest 3 ms resultant acceleration, sternum
  compression, Nij, peak neck tension/compression, and left/right femur axial
  compression.

Each occupant independently derives its dummy family from the ISO-MME
`fine_location_3` field of channels at that occupant's position:
`DummyType.MALE_50TH` (`H3`) or `DummyType.FEMALE_5TH` (`HF`). This allows,
for example, an H3 driver and an HF front passenger in the same report. The
derived value is exposed as the occupant's `dummy_type` manual input and may be
overridden before `calculate()` when the channel metadata is incomplete.

## Conservative assumptions

- Dummy containment is a typed manual input on each occupant and defaults to
  `False`. The report does not claim compliance until containment is positively
  confirmed from video or post-test inspection.
- ISO-MME longitudinal compression is treated as negative for chest deflection,
  neck compression, and femur force. Each femur is checked separately as the
  regulation requires; no left/right resultant is substituted.
- Dummy-specific channel patterns contain `H3` or `HF`. This prevents an HF
  threshold from being applied to an H3-derived Nij channel (or vice versa).
- When exactly one supported dummy identifier exists at an occupant position,
  the report selects it. With no supported identifier, or conflicting `H3` and
  `HF` identifiers at the same position, the report conservatively falls back
  to `HF`; an engineer must use the occupant's manual override if that fallback
  is not the actual setup.
- Driver and front-passenger channel-code positions default to `1` and `3`.
  The driver position is read from test metadata when present, and the opposite
  front position is derived unless explicitly overridden.
- Aggregation is strict pass/fail: every included criterion for both occupants
  must pass. Missing measurement channels remain `NA`; NaN values are not
  ignored.

## Explicitly outside the report

This measurement report does **not** decide whether the physical test itself met
the applicable vehicle classification, certification option, impact speed,
barrier angle, belt state, dummy positioning, instrumentation setup, or other
S8/S10/S16 conditions. It also omits the standard's equipment provisions,
seat-belt warning requirements, lateral and rollover tests, child suppression
tests, and low-risk-deployment/out-of-position provisions. Those require test
configuration records or different dummy/test reports and must be checked
separately.
